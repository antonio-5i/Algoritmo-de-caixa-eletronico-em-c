# Algoritmo de caixa eletrônico em linguagem c
Foi solicitado que eu criasse um algoritmo de caixa eletrônica onde o usuário digita o valor que deseja sacar e esse algoritmo verifique se o valor é múltiplo de 5 e depois me mostre quantas notas de 100, 50, 20, 10 e 5 eu preciso.
